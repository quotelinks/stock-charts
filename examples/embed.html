Embedding examples

Three ways to give a chart its data. All data here is fictional. ← All charts

1. JSON file or API URL (data-src)

<div class="ql-chart" data-type="target-range" data-src="data/acme-target-range.json"></div>
<script src="https://cdn.jsdelivr.net/gh/quotelinks/stock-charts@1.0.1/dist/ql-charts.min.js" defer></script>

2. Inline JSON (no extra request)

<div class="ql-chart" data-type="analyst-ratings" data-theme="dark">
  <script type="application/json">
    {"symbol":"ACME","strongBuy":11,"buy":8,"hold":4,"sell":1,"strongSell":0}
  </script>
</div>

3. JavaScript API

QLCharts.render(document.getElementById("eps"), "earnings-surprise", {
  symbol: "ACME",
  quarters: [
    { period: "Q2 '26", estimate: 1.25, actual: 1.34 },
    { period: "Q3 '26", estimate: 1.31, actual: 1.40 },
    { period: "Q4 '26", date: "2027-01-27", estimate: 1.38 }
  ]
}, { theme: "auto" });
